HTML

Site by: Ty Hicks





HTML stands for HyperText Markup Language. It is the standard code used to structure and arrange content on a webpage, acting as the fundamental building block of the World Wide Web.


Terminology Definition
Tag The keywords enclosed in angle brackets that tell a browser how to interpret content. They almost always come in pairs
Element The complete structural unit, consisting of the opening tag, the content inside, and the closing tag.
Attribute Special modifiers placed inside an opening tag that provide extra information or configuration data about the element.
